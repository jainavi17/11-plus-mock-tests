# 11+ Grammar School Mock Tests

Timed mock tests for Year 5 students preparing for UK grammar school (11+) entry.

- 40 papers, 400 questions across Maths, English, Verbal Reasoning and Non-Verbal Reasoning
- 10 questions per paper, medium to hard level
- Timed exams with auto-submit and detailed explanations for every question
- Learner profile and progress tracking (saved on the device)

Open `index.html` in a browser, or visit the GitHub Pages site for this repo.
